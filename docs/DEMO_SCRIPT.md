# Project Demo Script (approximately 2–3 minutes)

**Opening (20 seconds)**

“Hello, this is Cricbuzz LiveStats, my Python-based cricket intelligence and analytics project. I built it with Streamlit, SQLite, SQL, Pandas, and Plotly, and integrated a third-party cricket API for current match scores.”

**Command Center (25 seconds)**

“The cinematic homepage gives a quick overview of the synthetic demo database: matches, players, teams, total runs, and performance charts. The navigation opens the other analytics modules.”

**Match Center and Player Matrix (30 seconds)**

“Match Center displays stored matches and innings details. Player Matrix provides batting and bowling leaderboards, profiles, and metrics such as strike rate.”

**SQL Intelligence (30 seconds)**

“I created 25 SQL query recipes that analyze players, teams, venues, results, and performance. I can select a query, execute it, view the result, and export it to CSV. The query library is version-controlled.”

**Data Manager (25 seconds)**

“The Data Manager demonstrates CRUD: creating, viewing, editing, and deleting team and player records. The application validates input and uses SQLite constraints to help protect data integrity.”

**Live Cricket Scores (25 seconds)**

“This section connects to a cricket data API and retrieves current match information. I keep the API key in a local environment file, separate from the public GitHub repository. Local analytics remain available even if the API has a problem.”

**Closing (15 seconds)**

“The project demonstrates full-stack Python application development, relational data modeling, SQL analytics, data visualization, API integration, automated testing, and GitHub workflow. The local database contains synthetic demonstration records; live scores come from the external provider.”
