# Cricbuzz LiveStats

A cricket analytics dashboard built with Python, Streamlit, SQL, and interactive visualizations.

## Planned Features

- Live and recent cricket match information
- Player and team statistics
- SQL-driven cricket analytics
- Interactive charts and scorecards
- Database CRUD operations
- Custom SQL analytics interface
- Automated tests and documentation

## Technology Stack

- Python
- Streamlit
- SQLite and SQLAlchemy
- Pandas and Plotly
- REST API integration

## Local Setup

1. Create and activate a Python virtual environment.
2. Install dependencies from requirements.txt.
3. Copy .env.example to .env and configure credentials when required.
4. Initialize the database using the project setup instructions.
5. Run the application with Streamlit.

## Security

Never commit real API keys, passwords, or the local database to GitHub.
